# LINE Developers 設定手順

## 1. LINE Developersにログイン

1. [LINE Developers](https://developers.line.biz/ja/) にアクセス
2. LINEアカウントでログイン（個人アカウントでOK）

## 2. プロバイダーの作成

1. 「プロバイダー」をクリック
2. 「作成」をクリック
3. プロバイダー名を入力: `Unisia` または `株式会社UNISIA`
4. 「作成」をクリック

## 3. Messaging APIチャネルの作成

1. 作成したプロバイダーを選択
2. 「Messaging API」をクリック
3. 以下を入力:

| 項目 | 入力内容 |
|------|----------|
| チャネルの種類 | Messaging API |
| プロバイダー | Unisia（先ほど作成したもの） |
| チャネル名 | Unisia海外相談 |
| チャネル説明 | 留学・海外旅行の無料相談ボット |
| 大業種 | 旅行 |
| 小業種 | 旅行代理店 |
| メールアドレス | 会社のメールアドレス |

4. 利用規約に同意して「作成」

## 4. チャネルアクセストークンの取得

1. 作成したチャネルを開く
2. 「Messaging API設定」タブをクリック
3. 一番下の「チャネルアクセストークン」セクションで「発行」をクリック
4. 表示されたトークンをコピー → `.env` の `LINE_CHANNEL_ACCESS_TOKEN` に貼り付け

## 5. チャネルシークレットの取得

1. 「チャネル基本設定」タブをクリック
2. 「チャネルシークレット」をコピー → `.env` の `LINE_CHANNEL_SECRET` に貼り付け

## 6. Webhook設定（デプロイ後）

1. 「Messaging API設定」タブ
2. 「Webhook URL」に以下を入力:
   ```
   https://あなたのドメイン/webhook
   ```
   例: `https://unisia-line-bot.railway.app/webhook`
3. 「Webhookの利用」をONに
4. 「検証」ボタンで接続確認

## 7. 応答設定

1. 「Messaging API設定」タブの「応答メッセージ」で「編集」をクリック
2. LINE Official Account Managerが開く
3. 以下のように設定:

| 項目 | 設定 |
|------|------|
| 応答メッセージ | **オフ** |
| あいさつメッセージ | オンでもオフでもOK |
| Webhook | **オン** |

> ⚠️ 応答メッセージを「オフ」にしないと、ボットの返信と自動応答が二重に送られます

## 8. 友だち追加用QRコード

1. 「Messaging API設定」タブ
2. 「QRコード」をダウンロード
3. このQRコードを共有すると友だち追加できる

## トラブルシューティング

### Webhook検証が失敗する
- URLが正しいか確認（末尾に `/webhook` がついているか）
- サーバーが起動しているか確認
- SSL証明書が有効か確認（HTTPSが必須）

### 二重に返信される
- LINE Official Account Managerで「応答メッセージ」をオフにする

### メッセージが届かない
- 「Webhookの利用」がオンになっているか確認
- サーバーのログでエラーを確認
