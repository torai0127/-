# リッチメニュー設定ガイド

中継サーバーと連携するリッチメニューの設定方法。

## 概要

フラットサポートのリッチメニュー（6ボタン）に対応しています。

```
[リッチメニュー - フラットサポート]
┌─────────────────┬─────────────────┬─────────────────┐
│ 格安購入券      │ 海外保険案内    │ 海外LINE       │
│ サポート        │ サポート        │ サポート        │
│                 │                 │                 │
│ → 航空券ボット  │ → 相談ボット    │ → 相談ボット    │
├─────────────────┼─────────────────┼─────────────────┤
│ 帰国後転職      │ 海外留学無料    │ 海外緊急対応    │
│ サポート        │ 相談会          │                 │
│                 │                 │                 │
│ → 相談ボット    │ → 相談ボット    │ → 相談ボット    │
└─────────────────┴─────────────────┴─────────────────┘
```

**振り分けルール:**
- 格安購入券サポート → **航空券ボット**（unisia-flight-bot）
- その他5つ → **相談ボット**（unisia-line-bot）

## LINE Official Account Manager での設定

### 1. リッチメニューの作成

1. [LINE Official Account Manager](https://manager.line.biz/) にログイン
2. アカウントを選択
3. 「ホーム」→「リッチメニュー」→「作成」

### 2. テンプレートの選択

- **3分割（横並び）** がおすすめ
- または目的に応じたレイアウトを選択

### 3. 各ボタンの設定（フラットサポート用 6ボタン）

#### ボタン1: 格安購入券サポート（→ 航空券ボット）

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `menu_flight_ticket` |
| ラベル | 格安購入券サポート |

#### ボタン2: 海外保険案内サポート（→ 相談ボット）

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `menu_insurance` |
| ラベル | 海外保険案内サポート |

#### ボタン3: 海外LINEサポート（→ 相談ボット）

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `menu_line_support` |
| ラベル | 海外LINEサポート |

#### ボタン4: 帰国後転職サポート（→ 相談ボット）

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `menu_job_support` |
| ラベル | 帰国後転職サポート |

#### ボタン5: 海外留学無料 相談会（→ 相談ボット）

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `menu_study_abroad` |
| ラベル | 海外留学無料 相談会 |

#### ボタン6: 海外緊急対応（→ 相談ボット）

|------|--------|

| データ | `tab_advance` |

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `tab_premium` |

#### その他質問

| 項目 | 設定値 |
|------|--------|
| タイプ | ポストバック |
| データ | `tab_other` |

### 4. デザインのカスタマイズ

- 画像サイズ: 2500×1686px または 2500×843px
- 各ボタンにアイコンと説明テキストを配置
- Canvaなどで作成可能

### 5. 公開設定

- 「デフォルトで表示」をON
- 「メニューバーのテキスト」を設定（例：「メニュー」）

## Lステップ/エルメ側の設定

### Lステップの場合

リッチメニューはLステップ管理画面でも作成可能：

1. Lステップ管理画面 → リッチメニュー
2. 新規作成
3. ボタンアクションに「外部URL」または「タグ付け」を設定

**注意**: Lステップでリッチメニューを作成する場合、
Postbackではなく「タグ付け」+「シナリオ発動」で制御することが多い。
その場合は中継サーバーのキーワード振り分けを活用。

### エルメの場合

同様にエルメ管理画面でリッチメニューを作成可能。
ポストバックを使う場合は上記の設定を参照。

## トラブルシューティング

### リッチメニューが表示されない

1. 「デフォルトで表示」がONか確認
2. 公開設定を確認
3. 友だちを一度削除→再追加

### ボタンを押しても反応しない

1. Postbackデータが正しいか確認（スペースなど）
2. 中継サーバーのログを確認
3. Webhook URLが正しく設定されているか確認

### 意図しないボットに転送される

1. Postbackデータを確認
2. `src/config/routes.ts` のルール順序を確認
3. キーワード設定が競合していないか確認

## デザインテンプレート

Canvaで使えるテンプレート（サイズ: 2500×843px）:

1. 背景色: Unisiaブランドカラー
2. フォント: 見やすいゴシック体
3. アイコン: シンプルな絵文字 or Flaticon
4. コントラスト: 読みやすさ重視
